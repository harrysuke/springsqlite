# 2026-10-29 — SaaS Features Implementation

## What was done
Added four SaaS features to the Spring Boot (Kotlin) + JTE + MyBatis + SQLite project:

1. **Centralized Dashboard** — `/saas/dashboard` page showing total users, API keys, active webhooks, audit log count, usage summary, recent audit logs, recent webhook deliveries, daily usage chart.
2. **Robust APIs & Webhooks** — Full REST API for API keys (`/api/api-keys`), webhooks (`/api/webhooks`), plus webhook delivery service with HMAC-SHA256 signatures and retry logic. Webhook events fire on user CRUD operations (`user.created`, `user.updated`, `user.deleted`).
3. **Usage Analytics & Reporting** — Usage events logged automatically for every `/api/` request via `SaasInterceptor`. Aggregated by endpoint, method, status code, daily count. Available at `/saas/usage` and `/api/usage/summary`.
4. **Audit Logs** — Automatic audit logging of all mutations (POST/PUT/DELETE) on API endpoints. Viewable at `/saas/audit-logs` with filtering by action and actor, plus pagination. API at `/api/audit-logs`.

## Key decisions
- Used Jackson 3 (`tools.jackson.databind.ObjectMapper`) — Spring Boot 4 / Jackson 3 convention
- Webhook delivery uses `RestClient` with `SimpleClientHttpRequestFactory` for 10s timeout
- HMAC-SHA256 signatures for webhook payloads
- All SaaS management pages are admin-only; read-only API endpoints accessible to any authenticated user
- JTE templates use Java ternary syntax (not Kotlin elvis) and JS is in separate static files
